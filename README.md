# Centum Coaching Centre Demo

A responsive coaching-centre website and portal prototype.

## Demo access
Open Student Login, Teacher Login, or Admin Portal. Enter any ID and password (at least 3 characters). This is a frontend demonstration; authentication and data are simulated and no real accounts are created.

## Deploy
Connect this GitHub repository to Cloudflare Pages. Framework preset: None. Build command: leave blank. Build output directory: `/` (root).

## Files
- `index.html` – website and portal shell
- `styles.css` – responsive styling
- `app.js` – demo interactions
